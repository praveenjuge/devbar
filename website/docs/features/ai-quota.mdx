The top of the menu has one row for each AI tool you use. The row shows the quota window that's closest to running out: its percentage left, its name, and when it resets, with a bar underneath. The bar turns yellow below 25% and red below 10%. A tool you haven't used lately shows **Idle**.

## Supported tools

| Tool | What Devbar shows | Where the login comes from |
| --- | --- | --- |
| Codex | Session and weekly limits | `~/.codex/auth.json`, written by the Codex CLI |
| Claude | Session and weekly limits, per-model weekly limits, and monthly spend when your plan has them | Claude Code's Keychain item, or `~/.claude/.credentials.json` |
| Muse | Session and weekly limits | `~/.config/muse/auth.json` or the Keychain |

If you've signed in to Claude Code from more than one place, such as the terminal and the Claude desktop app, Devbar uses the newest valid login.

## Refreshing

Devbar refreshes every 10 minutes and whenever you open the menu. To check again while the menu is open, press ⌘R. Hold ⌥ while you click the menu bar icon to see **Refresh** with the time the last refresh finished.

If a refresh fails for a moment, like a network blip or a rate limit, Devbar keeps showing the last numbers it had. If the login itself is gone or expired, the tool's row says so and tells you how to sign in again, for example by running `claude`.

## Turning a tool off

Each tool has a switch under **Providers** in [Settings](/settings). A tool that's off isn't shown and isn't checked.
