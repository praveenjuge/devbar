Devbar checks for updates when it starts and every six hours, and downloads new versions in the background. When an update is ready, **Restart and update** appears in the menu below Settings. Choose it to update now, or quit Devbar as usual and the update installs before the next launch.

To check right away, open [Settings](/settings) and choose **Check for updates…**.

## How it works

Updates use [Sparkle](https://sparkle-project.org). Only the GitHub release marked **Latest** is offered, and each one includes a signed update feed and a signed, notarized app. Versions that are the same as or older than yours are ignored.

The update check sends no credentials and no system profile.

:::note
Copies of Devbar from before automatic updates were added need one manual update. Download the [latest release](https://github.com/praveenjuge/devbar/releases/latest) once, and updates are automatic from then on.
:::
